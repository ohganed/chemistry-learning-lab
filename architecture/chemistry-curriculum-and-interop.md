# Chemistry Structure Lab — 学習体系・連携設計 v1.0

## 長期方針（2026-11-06 確定）

- 高校「化学基礎」「化学」から大学学部・大学院まで段階的に進む。
- 大学の中心は **物理化学、量子化学、無機化学、有機化学、分析化学、生化学、高分子化学、理論化学、計算化学** の9分野とする。
- 専門・学際分野は重複を許すタグ／横断リンクとして登録する。特に熱力学・反応速度・分光・電気化学・固体・錯体・有機金属・天然物・材料・環境・土壌・植物栄養・肥料化学を忘れない。
- 章には安定ID、基礎知識（prerequisites）、学習目標、説明、数式、図のモデル条件、確認問題、次の章へのリンクを持たせる。
- 同じ概念を他分野の教材から参照可能にし、無用な重複実装を避ける。
- AIなし・オフラインで基本教材と学習記録を利用できる。AIは後付けの解説支援であり必須依存にはしない。
- 数式はLaTeX互換表現を基本とし、オフラインで描画できる構成へ発展させる。
- iPhone/iPad/Mac対応。GitHubでソース管理、Cloudflare Pagesで公開。
- 物理アプリ・語学アプリ・Learning & Life OS・Research OSとの連携を見据え、データ形式を安定化する。

## 学習分野の参照構造

高校化学 → 大学9基幹分野 → 49分野候補の専門・学際タグ。
大学分野は1本の一本道ではない。必要に応じて数学、物理、統計、プログラミング教材へ外部参照を張る。

## 共通データ交換仕様：learning-interchange / 1.0

JSONトップレベル：

```json
{
  "schema": "learning-interchange",
  "schemaVersion": "1.0",
  "sourceApp": "chemistry-structure-lab",
  "exportedAt": "2026-11-06T00:00:00.000Z",
  "records": [
    {
      "recordId": "chemistry-structure-lab-v01",
      "recordType": "app-local-state",
      "namespace": "chemistry",
      "payload": {}
    }
  ]
}
```

- `recordId` はアプリ内で使用した localStorage の既存キーに対応。現段階では旧形式をそのまま包む **可逆なアーカイブ**。個々の採点履歴への正規化は次段階。
- `recordType=app-local-state` は状態スナップショットであり、イベント履歴だと誤認しない。
- 他アプリは `schema` と `schemaVersion` を確認してから取り込む。未知キー／未知型は勝手に実行せず、隔離受信箱へ保存するか無視する。
- 個人情報・APIキーは含めない。出力ファイルはユーザーの手元で管理する。
- 化学アプリへの復元は既知のキーのみ、明示的な確認操作の後で行う。現在の記録の上書きを伴うため先にバックアップを推奨する。
- 自動同期、外部送信、別ドメインの localStorage アクセスは行わない。

## 国際化と言語設計（2026-11-06 追加）

- 原則として同じ教材IDに `ja` / `en` の2言語の教材本文、問題文、回答選択肢、解説を対応させる。
- 言語変更で学習進捗は失われず、章ID・設問IDは言語非依存とする。
- 29章の高校化学は日英2ページで共通 localStorage キーを使う初期実装。将来は共通教材データ＋翻訳辞書に整理して重複を減らす。
- 新設する大学化学教材は初期から日英両方の原稿を用意し、母語話者と専門家による査読、アクセスビリティ検証、根拠資料と教材バージョンの記録を行う。
- MIT等の大学への推薦は長期的な品質目標であり、提携・公式推薦の事実を示すものではない。

## Concept connections / 1.0（2026-11-06）

- 概念間の接続は一級の教材データとする。接続タイプ：prerequisite（前提）、analogy（類似）、contrast（対照）、application（応用）、reinterpret（後から再解釈）。接続には両端の安定ID、日本語・英語での科学的理由を持たせる。
- 最初の実装は高校化学29章の既存IDに対する20件の検証可能な接続。接続を章ページから閲覧できる。将来、章IDとは別に概念粒度のIDへ拡張する。
- 学習者が発見したつながりは `chemistry-concept-discoveries-v1` に `from,to,type,why,createdAt,provenance=learner-hypothesis` として保存する。科学的に査読した教材リンクとは必ず区別する。削除・JSON書き出し可能。
- 自由な学習順と単元の再訪を保証する。クイズに不合格でも進行制限しない。理解は他分野との接続によって時間差で深まることを許容する。
- 双方のページで同じ章IDを使用し、概念ネットワークを日本語・英語からアクセス可能にする。個人の説明文は自動翻訳しない。
- 保存・書き出しは端末内。既存の `learning-interchange/1.0` にも個人の発見の保存状態を追加する。自動同期なし。

## 概念粒度の試作：化学平衡（2026-11-06）

- `equilibrium-concept-lab.html` に10個の安定した概念IDと11件の理由付き接続を登録。高校29章の既存IDへリンクする。
- 反応速度、可逆反応、動的平衡、濃度、反応商、平衡定数、平衡移動、酸電離、緩衝作用、ギブズエネルギーを横断する。
- 重要なモデル条件（活量基準、理想希薄溶液の近似、定温条件、閉鎖系の前提）を明示する。
- 学習者の再解釈メモは `chemistry-fine-concept-insights-v1` に概念ID・本文・日時・provenanceを保存。確認テスト・進行ロックなし。日本語／英語で同じ概念IDを使用。自由記述は自動翻訳せず保存。
- 次段階はデータと表示の分離、大学化学側の概念IDとの連結、ネットワーク表示、学習者による関係追加とレビュー。

## Concept Atlas / 1.0 — 横断探索（2026-11-06）

- `concept-atlas.html`: 22概念・22の理由付き接続。原子構造、物質量・化学量論、化学平衡を横断する。
- 各概念に日英名称・短い定義・既存高校化学章IDを保持。前提・類似・対照・応用・再解釈の5種を区別する。
- 個人の発見は `chemistry-atlas-discoveries-v1` に端末内保存し、JSON書き出し可能。教科書側の知識と学習者の仮説を混同しない。
- 既存の学習記録のキー・問題・進行は変更せず、確認問題の成績で移動を制限しない。
- 今後は22概念を大学化学向け概念IDと連携し、概念データを別JSONに分離して自動検証できるようにする。

## 複数分野への展開（2026-11-06）

- `cross-domain-concept-lab.html` に化学結合・酸塩基・酸化還元の3分野、27概念、31本の理由付き接続を日英で追加。
- 章IDから独立した概念IDを各分野内で使用。本文の解説、問い、関係の理由、元の高校化学教材へのリンクを明示する。
- 記録は `chemistry-cross-domain-insights-v1` として保存し、旧学習記録を変更せず `learning-interchange/1.0` の書き出し・復元対象に追加。
- 既存のトップ画面と概念ページから新教材を開ける。進行制限なし、AI不要、PWAキャッシュに追加。
- 今後は分野横断のグローバル概念ID、教材データと表示の分離、テスト自動化、教育上の有効性の検証を行う。

- 分野を横断する7本の接続を `BRIDGES` として追加（結合↔酸塩基、結合↔酸化還元、酸塩基↔電気化学）。各関係に日英の理由を付け、クリックで別分野の概念へ移動できる。
- 新しい概念の追加時は `NODES` と `EDGES` に加え、必要に応じて分野横断リンクを登録し、関連の科学的妥当性を確認する。

## 知識アトラスの共通データ（2026-11-06 v1.1）

- `data/chemistry-knowledge-atlas-v1.json` を表示画面から分離した第一級データとする。形式は `chemistry-knowledge-atlas / 1.0`。
- 初期データは高校29章それぞれに2概念、大学9基幹分野＝計67ノード。章内29、大学への導線29、章間30、大学分野間8＝計96エッジ。
- 各ノードには言語中立ID、教育段階、日英名称、章への対応、短い文脈を持たせる。各エッジに関係種別、日英の理由と provenance を持たせる。
- `knowledge-atlas.html` は日英切替、絞り込み、検索、既存章へのリンク、学習者独自の概念接続と再解釈の記録を扱う。
- 学習者データは `chemistry-atlas-notes-v1` に別保存し、既存の回答・メモとは分離して保存・復元可能。教材側の `curated-draft` と利用者の `learner-hypothesis` は区別。
- 画面は既存コンテンツを壊さず追加。将来、概念ノードを増やす際にノードの安定IDを維持し、同じ概念を高校・大学双方から参照する。数値的な評価や理解度ゲートは必須にしない。
- 注意：初期の96接続は教材編集初稿であり、専門家査読を完了したという意味ではない。多義的な前提関係や学習者の反証を許す。
