# 高校化学を「独学できる教科書」にするための完成基準

## 目的と方針

- 化学基礎・化学の知識を、教師が隣で口頭補足しなくても学習者自身が読み進められる形にする。
- ただし説明量の増加だけで自律学習が保証されるとは考えない。
- 知識のネットワーク化、既知知識からの新しい理解、後から戻って再解釈できる仕組みを中心にする。
- 理解度確認は任意であり、正答できなくても次へ進むことを認める。
- 学習方法は「原理から／例題から／つながりから」など、学習者が変更できる。
- 教材側で登録した知識と、学習者自身が見つけた仮説は混同しない。

## 第2段階：因果をつなぐ徹底解説と計算例（2026-11-06）

- 29章すべてに日英の新しい5視点解説（計145視点）を追加。各章は現象の観察、粒子のメカニズム、式・モデルと単位、前提条件と限界、他の知識からの再解釈を別データとして収録。
- 16章の定量・構造推定問題に、5段階の理由を明示したガイドを追加。例：同位体加重平均、結晶密度、物質量、量論、気体、希釈、浸透圧、反応熱、速度論、平衡、弱酸、滴定、電気分解、溶解度積、有機分子の不飽和度、高分子の分子量。
- データは既存の `data/chemistry-depth-[0-5].json` の `reasoning` と `guidedExample` に追記。既存章ID、クイズID、学習者メモの保存形式は維持。
- `chemistry-depth-viewer.js` で開閉式表示。選択できる経路は原理・徹底解説・例題・知識の接続・（一部章で）計算の5種類。最初から長文すべてを画面へ展開しない。
- GitHub Actionsで29章×5視点の日英本文、16例題×5ステップの内容・データ対応、HTMLとJS構文、オフラインキャッシュを自動検証。
- **編集初稿であり、科学専門家による独立査読や利用者の学習効果検証が完了したことを意味しない**。


## 第3段階：概念が必要になった土壌から説明する（2026-11-07）

**教材設計の最優先原則：定義・公式が先ではない。科学者がその概念を必要とした現象・問題から始める。**

教材に詳細な説明を与えると、学習者が考えなくなるわけではない。知識を十分に説明することで、既存の知識との関係、矛盾、新しい疑問が生まれ、自発的に考えるための材料が増える。説明をわざと欠落させて「考えさせる」設計は採用しない。

各章を本質的に書き直す際のチェック：

1. その概念が登場する前の世界では、何を観察でき、何を説明できなかったのか。
2. 何を確かめようとするうちに、既存の概念だけでは不十分になったのか。
3. 以前に学んだどの知識を土台にできるか。必要な用語は定義して説明できているか。
4. **初めてここで**新概念を定義し、その定義が問題解決にどう役立つか説明する。
5. 定義・関係式の成立条件を明記する。等式は意味と導出を示し、暗記の対象にしない。
6. 現象・粒子像・測定・数式を往復して、例題を解く理由を文章で説明する。
7. 何がまだ説明できないか、条件を変えるとどこが崩れるかを示す。
8. 後の章で理解を読み直すための接続を設ける。学習順や理解度テストを必須にしない。

**熱化学 2-0 の先行改稿**：日英15節の「概念が必要になった理由」を `originJourney` として収録。系と周囲、熱・仕事・内部エネルギー、定積と定圧、ピストンの仕事、熱力学第一法則、エンタルピーの定義と限界、符号、反応状態、ヘスの法則、自由エネルギーとの接続まで丁寧に扱う。短い暗記用の説明と式は、この章で学び始める際に先頭へ出さない。

**残り28章の進捗**：従来の多層説明はあるが、この新しい「概念の発生理由から説明する」基準に沿った改稿は未完了。全29章を同じ品質だと宣言しない。章ごとの段階的改稿・個別検証を継続する。学習記録と章IDは維持する。

## 現段階の意味

**高校化学29章の詳細解説データを一巡した編集初稿**であり、次のすべてを満たす完成版ではない。教材数の充実と、独学の有効性は区別して判断する。

- **設計上の到達**：高校・大学への主要な知識接続、全章への多層説明と例題を準備。
- **未検証**：教材のすべてを専門家が科学的に査読し、実際の高校生・独習者に独学で利用してもらって成果を確認する工程。
- **未完了**：図示・実験の可視化、広い難度の計算演習、問題の質と多様性、教材の細部、アクセシビリティの実機評価。

## 教科内容を取りこぼさないための点検領域

日本の高校科目「化学基礎」「化学」の領域を以下の観点で繰り返しチェックする（正式な教材認定を意味しない）。

1. 物質の分類・分離・測定・化学と人間生活
2. 原子・同位体・電子配置・周期性・化学結合・結晶
3. 物質量・量論・気体・状態変化・溶液・溶解度・束一的性質
4. 反応エンタルピー・ヘスの法則・反応速度・触媒・平衡
5. 酸塩基・pH・中和滴定・緩衝液・酸化還元・電池・電気分解
6. 非金属・金属・錯体・定性分析・工業化学
7. 有機構造・異性体・脂肪族・芳香族・酸化・エステル・糖・アミノ酸
8. 合成高分子・天然高分子・材料・環境利用
9. 探究の方法、測定不確かさ、実験安全、科学的説明の妥当性

参考となる公的資料：文部科学省『高等学校学習指導要領解説 理科編 理数編』（平成30年告示）。
https://www.mext.go.jp/content/20230626-mxt_kyoikujinzai02-000033064_06.pdf

## 次に完成へ近づける作業

優先順位は、文章量よりも**一人で理解が進む仕組み**を指標に決める。

1. 定量分野に段階別の解説付き例題を増やす（物質量、気体、熱化学、平衡、滴定、電気分解）。
2. 全章にマクロな観察・粒子モデル・反応式／数式の三つの表現を結ぶ図を加える。
3. 理解の深まりを支える「この知識から以前の章を読み直す」導線を概念IDで自動表示する。
4. 各章に安全な仮想実験または検証可能な公開データ例を置き、問い・予想・反証を任意で試せるようにする。
5. 日英の科学用語の対応・数式・単位・図のモデル条件を専門家が査読し、修正履歴を残す。
6. iPhoneの文字サイズ、スクリーンリーダー、操作領域、オフライン復帰、保存・復元を実機で検証する。
7. 実際の独習者の理解過程を評価し、つまずき・再訪・知識の接続を教材改善に反映する。強制テストは行わない。

## データ互換性

- 現行 `high-school-chemistry.html` と `high-school-chemistry-en.html` の章ID・問題IDと既存 `localStorage` 回答記録は維持。
- `data/chemistry-depth-[0-5].json` と `data/chemistry-depth-extensions-v1.json` が詳細原稿。
- `chemistry-depth-viewer.js` は読み込んだ章の説明を表示する専用コンポーネント。
- 学習者のメモは `chemistry-depth-reflections-v1` に保存。教材側データへの書き込みは行わない。
