# Chemistry Structure Lab

高校化学から大学化学へ段階的に進む、AIなしでも利用できるHTMLベースの化学学習アプリです。

## 現在の教材（2026-11-08 章ごとに説明方法を選ぶ改稿版）

- ホーム、学習分野マップ、導入教材4講
- 原子・化学結合・物質量・化学反応式の説明
- 探索型周期表（最初の36元素）
- 電子配置インタラクティブ教材（原子番号1〜30、軌道とスピン、Cr/Cuの例外）
- 原子軌道・4つの量子数・スピンの対話型教材と5問の理解確認（模式図は厳密な確率等値面ではありません）
- 高校化学29章の日英詳細解説：計87節、29の解説付き例題、29の誤解しやすい点、29の知識接続、29の任意探究問題を収録。
- **29章すべてに日英の概念起点型解説を追加：計192節。** 実験で現れる矛盾、粒子模型、式の導出、比較・反証、材料構造など、各章に適した説明から始める。従来の本文・例題は残し、理論の裏付けを独立した節で充実させた。
- **87の既存コア項目ごとに、説明方法を個別選択。** 観察・対照実験、数式導出、ベクトル模型、構造物性、速度・平衡、科学的証拠など10種類の方法から選んだ理由を `data/chemistry-teaching-approaches-v1.json` に記録。これは教材編集の品質管理用であり、学習者に特定の順序を強制しない。
- **21種類のオリジナル科学図表**を対応する説明節に挿入。定常波、分子双極子、気体の壁面衝突、浸透、滴定曲線、電気化学、有機分子の構造、芳香族性、高分子鎖などを、図の限界と成立条件とともに説明。日英どちらでも表示。
- 発展・分野横断の解説18項目。状態図、溶解度積、工業化学、測定と不確かさ、環境化学、立体異性体などを補強。
- 各章で「原理から」「例題から」「知識のつながりから」学ぶ経路を選べる。iPhoneでは長い内容を段階的に開いて閲覧可能。
- 29章すべてに「現象 → 粒子モデル → 式・モデル → 成立条件と限界 → 後から再解釈」の **5視点×29章＝145の徹底解説** を日英で追加。長文はiPhoneでは折りたたみ表示。
- 16の計算・定量・構造推定テーマでは、**何を求めるか／前提・条件／式の意味／計算／検算と限界**を5段階で読むガイド付き例題を追加。
- 「原理から・徹底解説から・例題から・つながりから」の学習入口を用意。該当章では「計算を一歩ずつ」も選択できる。
- 既知の知識が新しい説明を生む「知識の橋」11テーマ・日英34段階の説明を全29章に追加。保存力→状態量、圧力と膨張仕事、ベクトルと分子の極性、回路と酸化還元、平衡と酸塩基など。
- [経路と状態量の実験ページ](state-function-lab.html)：保存力・摩擦の仕事と、熱・仕事・内部エネルギーの経路依存性を操作して比較。定義が異なる部分とモデルの限界も説明（日英切替）。
- **学習画面の順序を全29章で変更**：公式や短い要約を先に出さず、詳細な説明を先に読み、要点は最後の折りたたみ欄で確認。
- 確認問題の回答後も説明の開閉状態・入力途中のメモを失わないよう、解説全体を再描画しない。
- **無機化学を原理から再構成（Pfennigの教育的特長を参考）**：非金属・典型金属・遷移金属と錯体・無機分析の4章に、日英各8節（合計32節）の段階的説明、12の理論モデル比較、17の導出手順、4種のオリジナル科学模式図を追加。化学種を識別し、モデルが何を説明できるか／できないかを明記。
- 理論の例：ハロゲン置換反応の電子収支と標準電位、Alの不動態化と両性、八面体結晶場のd軌道分裂（3a+2b=0）、AgClの溶解平衡と銀アンミン錯体生成（K=Ksp×β₂）。図・式・言葉を対応させる。
- 無機化学の全体像と未完成事項は [教材の完成基準](architecture/high-school-chemistry-completion.md) に明記。参考書の文章や図版の転載はしていません。
- 29章に対応する既存の確認問題と学習履歴・検索は維持。理解度による進行制限なし。
- [知識アトラス](knowledge-atlas.html) は高校化学と大学化学9分野の67概念・96接続を探索。
- 各講の確認問題と正誤のローカル記録
- スマートフォン・タブレット・PC対応
- Service Worker による初回オンライン表示後のオフライン閲覧

## 日英バイリンガル教材

[高校化学（日本語）](high-school-chemistry.html) と [High School Chemistry (English)](high-school-chemistry-en.html) は29章の説明・問題・解説をそれぞれの言語で持ち、共通の章ID・進捗記録を使用します。英語表示を追加したのは高校化学29章であり、他の専用ページの全訳は今後の課題です。国際的な大学で推薦されうる品質を長期目標として、英語の科学的正確性・アクセシビリティ・検証可能性を重視します。いかなる大学からも推薦・承認を受けたと主張しません。

## 大学化学の体系・他アプリ連携

学習分野とデータ交換の設計書は [architecture/chemistry-curriculum-and-interop.md](architecture/chemistry-curriculum-and-interop.md) を参照。大学化学は9基幹分野と専門・学際タグで整理します。学習記録は [learning-interchange.html](learning-interchange.html) から共通JSON形式で書き出し・復元できます。現段階では手動でのファイル受け渡しで、自動同期ではありません。

## 公開

GitHubをCloudflare Pagesに接続し、Production branchを `main`、Framework presetを `None`、Build commandを空欄、Build output directoryを `/` にして公開します。

## 教材の編集

高校化学の詳細教材は `data/chemistry-depth-0.json` 〜 `chemistry-depth-5.json`、発展教材は `data/chemistry-depth-extensions-v1.json` に分離しています。 科学図表のロジックは `chemistry-topic-visuals.js` にあり、対応する章の説明節だけに表示します。 学際的な知識の橋は `data/chemistry-knowledge-bridges-v1.json` に分離し、公式前の説明と類推の限界を扱います。表示ロジックは `chemistry-depth-viewer.js` です。旧29章と確認問題は変更せず、詳細原稿を追加読み込みしています。

[完成基準・未解決課題](architecture/high-school-chemistry-completion.md) には、説明の詳細化と自律学習の成立を区別する品質基準を記録しています。教材データの検証は GitHub Actions と `tests/validate-depth.mjs` で実施します。

## 注意

29章の詳細原稿は整備しましたが、専門家査読・全範囲の細目照合・豊富な演習・実機による独学検証が済んだ完成版ではありません。確認問題の学習記録はブラウザのlocalStorageに保存され、端末間の自動同期は未実装（JSONの手動エクスポートには対応）です。初回アクセス時はオンライン接続が必要です。オフラインにする前に一度ページを開いてください。
